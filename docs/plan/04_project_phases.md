# Lộ trình triển khai

## Giai đoạn 1: Khởi tạo và Thiết kế (Tuần 1 - Tuần 4)
- Khảo sát yêu cầu chi tiết, thống nhất bộ chuẩn API giao tiếp dùng chung cho các hãng hàng không.
- Thiết kế UI/UX cho ứng dụng Web.
- Thiết kế chi tiết kiến trúc hệ thống, Database Schema và các luồng API (API Flows).
- Thiết lập môi trường phát triển (CI/CD, Docker).

## Giai đoạn 2: Phát triển Core MVP (Tuần 5 - Tuần 12)
- Xây dựng hệ thống Authentication và cơ sở hạ tầng chung (BuildingBlocks).
- Phát triển Module Flights: Hỗ trợ tạo chuyến bay và tìm kiếm.
- Phát triển Module Bookings: Xử lý đặt chỗ và thanh toán cơ bản.
- Tích hợp API chuẩn với ít nhất 1 hãng hàng không đối tác đầu tiên.
- Hoàn thiện Web Frontend cho luồng đặt vé chính.

## Giai đoạn 3: Mở rộng tính năng (Tuần 13 - Tuần 18)
- Phát triển Module Reviews để khách hàng đánh giá sau chuyến bay.
- Phát triển Module Articles (CMS) để quản trị viên đăng bài báo, tin tức hàng không.
- Hoàn thiện Module Promotions để áp dụng mã giảm giá, chương trình khuyến mãi.
- Tối ưu hóa hiệu năng tìm kiếm chuyến bay.

## Giai đoạn 4: Kiểm thử và Triển khai (Tuần 19 - Tuần 22)
- Kiểm thử tích hợp hệ thống (Integration Testing) và kiểm thử đơn vị (Unit Testing).
- Load Testing cho các API tìm kiếm chuyến bay.
- Triển khai thử nghiệm (Beta/UAT) với dữ liệu thực.
- Triển khai Production và giám sát hệ thống.
